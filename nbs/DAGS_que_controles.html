Buenos y malos controles

Aunque hemos visto previamente las diferentes estructuras en un DAG, en este vamos a simular datos para convencernos de que efectivamente hay buenos y malos controles.

Variable de confusión

DAG

Code
library(ggdag)
#| echo: true

dag1 <- dagify(
  x ~  z, 
  y ~ z + x,
  exposure = "x",
  outcome = "y",
  coords = list(
    x = c(
      x = 1,
      z = 2,
      y = 3
    ),
    y = c(
      x = 1, 
      z = 2,
      y = 1
  )
))
ggdag(dag1) + theme_dag()

Veamos el conjunto de ajuste:

Code
ggdag_adjustment_set(dag1, exposure = "x", outcome = "y")

El modelo correcto dado este dag es ajustar por Z. Veamos si es cierto, simulando la estructura del dag.

Cuando tenemos una variable mediadora podemos estar interesados en el efecto total o en el efecto directo.

Efecto total

Code

  theme_dag()

Efecto directo

Code
ggdag_adjustment_set(dag_med, exposure = "x", outcome = "y", effect = "direct") +
  theme_dag()

Simulamos un efecto total de x sobre y igual a 6, pero totalmente mediado sólo por z, y que el efecto directo de x sobre y es 0.

Efecto total es sin ajustar por z y el efecto directo es ajustando por z

## Buenos y malos controles

Aunque hemos visto previamente las diferentes estructuras en un DAG, en este vamos a simular datos para convencernos de que efectivamente hay buenos y malos controles. 




### Variable de confusión

__DAG__

```{r}
library(ggdag)
#| echo: true

dag1 <- dagify(
  x ~  z, 
  y ~ z + x,
  exposure = "x",
  outcome = "y",
  coords = list(
    x = c(
      x = 1,
      z = 2,
      y = 3
    ),
    y = c(
      x = 1, 
      z = 2,
      y = 1
  )
))
ggdag(dag1) + theme_dag()

```

Veamos el conjunto de ajuste: 

```{r}
#| echo: true

ggdag_adjustment_set(dag1, exposure = "x", outcome = "y")

```


El modelo correcto dado este dag es ajustar por Z. Veamos si es cierto, simulando la estructura del dag.

```{webr-r}

z <- rnorm(300)

x <- 2 + 3*z + rnorm(300)

y <- 2 + x + z + rnorm(300)

# Modelo incorrecto
lm(y ~ x) |> confint()

# Modelo correcto debería dar coeficiente de x = 1

lm(y ~ x + z ) |> confint()

```

Simulamos un efecto total de `x` sobre `y` igual a 6, pero totalmente mediado sólo por `z`, y que el efecto directo de `x` sobre `y` es 0.

```{webr-r}
#| warning: false
#| message: false
library(tidyverse)
x <- rnorm(800)
z <-  3*x + rnorm(800)
y <- 2*z + rnorm(800)
d <- tibble(x, y, z)

# Para valores similares de Z el efecto de X sobre Y es 0, 
# Se puede observar haciendo  "cortes" en Z para verlo
d  |>
  mutate(z_cut = cut_interval(z, 9)) |>
 ggplot(aes(x = x, y = y)) +
  geom_point(aes(color = z_cut)) +
  geom_smooth(method = "lm", se = FALSE, color = "black", linewidth= 2) +
  geom_smooth(aes(color= z_cut), method = "lm", se = FALSE)

```

Efecto total es sin ajustar por `z` y el efecto directo es ajustando por `z`

```{webr-r}

# efecto total
lm(y ~ x, data = d) |> confint()

# efecto directo
lm(y ~ x + z, data = d) |> confint()

```

```{webr-r}

f <- function(bzx = 2, bxy =2, n = 100){
  z <- rnorm(n, 4, 2)
  x <-  2 + bzx*z + rnorm(n)
  y <-  2 + bxy*x + rnorm(n)
  d <- tibble(x, y, z)
  bx_preciso = coef(lm(y ~ x, data = d))[2]
  bx_parasito = coef(lm(y ~ x + z,  data = d))[2]
 return(c(
    unlist(bx_preciso), unlist(bx_parasito)))
}


sim <- replicate(400, f(n = 200))

d <- data.frame(bx_preciso = sim[1,], bx_parasito = sim[2,])

d <- d  |> 
  pivot_longer(cols =everything())

d  |> 
  ggplot(aes(x = value, fill = name)) +
  geom_density()





```



### Amplificación del sesgo

A veces, si ajustamos por un pretreatment pero hay una variable de confusión
no observada, podemos incurrir en amplificación del sesgo


DAG

```{r}
#| echo: true
dag3 <- dagify(
  x ~  z + u, 
  y ~  x + u,
  coords = list(
    x = c(
      x = 1,
      z = 1,
      u = 2,
      y = 3
    ),
    y = c(
      x = 1, 
      z = 2,
      u = 1.5,
      y = 1
  )
)
)

ggdag(dag3) + theme_dag()

```

Conjunto de ajuste:

```{r}
ggdag_adjustment_set(dag3, exposure = "x", outcome = "y")
```

Tenemos que ajustar por `u`, pero `u` es no observada:

```{webr-r}

z <- rnorm(200)
u <- rnorm(200)


x <-  1 + 2*z + u + rnorm(200)

y <- 1 +   x + u + rnorm(200)

d <- tibble(x, y, z)

# ajustar por la variable pre-treatment amplifica el sesgo

lm(y ~ x, data = d) |> confint()
lm(y ~ x + z, data = d) |> confint()


```

Simulemos para ver mejor la diferencia

```{webr-r}

f <- function(bzx = 2, bxy =1, n = 100){
  z <- rnorm(n)
  u <- rnorm(n)

  x <-  1 + bzx*z + u + rnorm(n)
  y <-  1 + bxy*x + u + rnorm(n)
  d <- tibble(x, y, z)
  bx_sesgado = coef(lm(y ~ x, data = d))[2]
  bx_sesgo_ampli = coef(lm(y ~ x + z,  data = d))[2]
 return(c(
    unlist(bx_sesgado), unlist(bx_sesgo_ampli)))
}


sim <- replicate(400, f(n = 200))

d <- data.frame(bx_sesgado = sim[1,], bx_sesgo_ampli = sim[2,])

d <- d  |> 
  pivot_longer(cols =everything())

d  |> 
  ggplot(aes(x = value, fill = name)) +
  geom_density()


```
